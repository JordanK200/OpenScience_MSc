# Raw-data Directory

This directory contains original, unmodified input data. These files are downloaded automatically by the `01` scraping scripts, or can be retrieved from the Google Drive backup linked in `data/README.md`.

- **RAW_CIHR.csv** – Raw CIHR funding data scraped by `01_CIHR_scrape.R`.
- **RAW_NSERC.csv** – Raw NSERC funding data scraped by `01_NSERC_scrape.R`.
- **RAW_PLOS.csv** – Raw open science practice data for PLOS ONE publications.
- **RAW_PLOS_Comparator.csv** – Raw open science practice data for the comparator journal sample.
