# Sample Data Directory

This directory contains small random samples of the cleaned datasets, intended for development and testing without loading the full data.

- **Master_Sample.csv** – 2,500-row sample of `Cleaned_Master_Data.csv`. One row per author–publication pair.
- **Author_Sample.csv** – Sample of `Author_Level_Data.csv`. One row per unique author.

For full variable descriptions, see `data/clean-data/Data_Dictionary.md`.
