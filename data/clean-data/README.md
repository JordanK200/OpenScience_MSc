# Clean-data Directory

This directory contains fully processed, analysis-ready datasets produced by `02_Data_Cleaning.Rmd`. See `Data_Dictionary.md` for full variable descriptions.

- **Cleaned_Master_Data.csv** – Author–publication-level dataset (45,284 rows × 56 columns). One row per author–publication pair.
- **Cleaned_Master_Data.rds** – Same as above in R's native binary format.
- **DOI_Level_Data.csv** – Publication-level dataset (5,160 rows × 19 columns). One row per unique DOI.
- **Author_Level_Data.csv** – Author-level dataset (2,099 rows × 13 columns). One row per unique author.
